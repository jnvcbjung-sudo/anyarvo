# ANYARVO — Official one-page website

Static site (single `index.html` + `images/`). Deployed via GitHub Pages.

## Files
- `index.html` — the whole site
- `images/` — hero, product photos (breeze/sand/terra), logos
- `CNAME` — custom domain (anyarvo.com)
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Update
Edit `index.html` or swap an image in `images/` (keep the same filename), then commit & push. GitHub Pages redeploys automatically.
